## 🔵 Phase 1 — Foundations
**Python · SQL · Excel**

The goal of Phase 1 is to build solid fundamentals before touching any analytics library or visualization tool. No shortcuts — get the core right first.

### What to Learn

**Python (via Kaggle, starting from scratch):**
- Syntax basics, variables, data types, functions, conditionals, loops
- Strings and lists — indexing, slicing, built-in methods
- Dictionaries and sets — when and why to use them
- List comprehensions — writing clean, Pythonic code
- File I/O — reading and writing `.txt` and `.csv` files
- Working with external data — loading files, iterating rows, basic transformations
- Writing reusable functions and simple scripts

**SQL (from the ground up):**
- SELECT, WHERE, ORDER BY, LIMIT
- GROUP BY and aggregate functions — COUNT, SUM, AVG, MIN, MAX
- JOINs — INNER, LEFT, and when to use each
- CASE WHEN for conditional logic
- Filtering with HAVING

**Excel (analyst basics):**
- Pivot Tables and Pivot Charts
- XLOOKUP and VLOOKUP
- Data cleaning — removing duplicates, handling blanks, text functions

### Resources

- [SQLBolt](https://sqlbolt.com) — interactive SQL lessons from scratch
- [SQLZoo](https://sqlzoo.net) — SQL practice with real databases
- [Kaggle Python Course](https://www.kaggle.com/learn/python) — Python for data, free
- [freeCodeCamp Data Analysis with Python](https://www.freecodecamp.org/learn/data-analysis-with-python/) — Pandas + NumPy projects
- [LeetCode SQL](https://leetcode.com/problemset/database/) — interview-level SQL practice
- [Alex The Analyst (YouTube)](https://www.youtube.com/@AlexTheAnalyst) — Excel, SQL, Python walkthroughs

### Projects

- `phase-1-foundations/python/subtitle-analyzer/` — Python script that reads .srt files and analyzes word frequency
- `phase-1-foundations/sql/analytics-queries.sql` — 20+ business-question SQL queries on a sample database
- `phase-1-foundations/ph-ecommerce-analysis/` — early exploration of a Philippine e-commerce dataset

**Milestone:** 2 working scripts + 20 SQL queries with documented findings.

## 🟢 Phase 2 — Analytics Core
**Pandas · NumPy · EDA · Statistics**

Phase 2 is where Python becomes a real analysis tool. The focus shifts from syntax to thinking analytically — asking business questions, cleaning messy data, drawing conclusions from numbers.

### What to Learn

- Pandas deeply — DataFrames, merge, groupby, apply(), pivot_table, handling nulls
- NumPy array operations for numerical work
- Exploratory Data Analysis (EDA) — profiling datasets end-to-end
- Statistics for analysts — mean, median, std deviation, distributions, correlations
- Advanced SQL — window functions, CTEs, subqueries

### Resources

- [Kaggle Pandas Course](https://www.kaggle.com/learn/pandas) — best quick Pandas course, free
- [Real Python — Pandas EDA](https://realpython.com/pandas-python-explore-dataset/) — highly practical walkthrough
- [Statistics with Python — Coursera](https://www.coursera.org/learn/statistics-with-python) — University of Michigan, free to audit
- [Mode SQL — Window Functions](https://mode.com/sql-tutorial/sql-window-functions/) — best window function guide online
- [Rob Mulla (YouTube)](https://www.youtube.com/@RobMulla) — EDA walkthroughs on Kaggle datasets
- [Towards Data Science](https://towardsdatascience.com) — practitioner-written articles

### Projects

- Full EDA on a Kaggle dataset (Titanic, Netflix, or PH-specific data)
- Python + SQL combined reporting pipeline
- Documented findings written as plain English insights (not just code)

**Milestone:** 2 GitHub repos with full READMEs and documented findings.

## 🟡 Phase 3 — Dashboards & Visualization
**Power BI · Matplotlib · Seaborn · Data Storytelling**

Phase 3 is about communicating data, not just analyzing it. A correct insight nobody understands is worthless.

### What to Learn

- Power BI from scratch — interface, Power Query, data model, DAX basics
- Python visualization — Matplotlib and Seaborn for publication-quality charts
- Choosing the right chart for the right message
- Color theory and layout for dashboards
- Data storytelling — context, clutter reduction, insight-first thinking

### Resources

- [DataCamp Power BI Track](https://www.datacamp.com/tracks/data-analyst-in-power-bi) — co-created with Microsoft, prepares for PL-300
- [Guy in a Cube (YouTube)](https://www.youtube.com/@GuyInACube) — best Power BI channel, run by ex-Microsoft team
- [Kaggle Data Visualization](https://www.kaggle.com/learn/data-visualization) — Seaborn-focused, free
- [Storytelling with Data](https://www.storytellingwithdata.com) — the definitive resource on chart communication
- [Power BI Public Gallery](https://app.powerbi.com/view) — study real dashboards for design inspiration
- [Chandoo (YouTube)](https://www.youtube.com/@chandoo_) — Excel + Power BI, very practical

### Projects

- Power BI dashboard on Philippine business data (Sales / E-commerce / COVID)
- Python visualization portfolio — 5+ chart types on real datasets
- Redesigned "bad chart" exercise — critique and rebuild

**Milestone:** 1 published Power BI dashboard + consistent LinkedIn posting habit.
