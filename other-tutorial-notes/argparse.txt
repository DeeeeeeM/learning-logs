Arguments on CLI is all text / str
- Enforcing arguments (if function can have 1 or more inputs)
- Can be required or optional
- Arguments can be grouped

Steps:
Import lib
create parser
add one or more arguments to the parser
call .parse_args()
act on the result


parser = argparse.ArgumentParser() <-- Creates the parser object
parser.add_argument('name') <--- Require an argument called name
args = parser.parse_args() <--- reads what you typed in terminal

for _ in range(args.num):
    print(f"I'm sorry {args.name}, Cant do that")
