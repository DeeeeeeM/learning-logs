## Code Structure in Java

**What goes in a source file?** Your source code .java file containing a class definition, it represents a piece of your program inside a curly braces

**What goes in a class?** Class contains one or more methods. It has your method on how to bark, play, stay, etc... inside curly braces.

**What goes in a method?** Inside your methods are instructions on how your method should perform. For example, it has step by step instructions how to bark (Open mouth wide > Let air out from lungs and hit your voice box, then output is a bark sound). It just means your instructions on how will it act.

## Everthing goes in a class in Java
When you run a program, that program is really a class.

Running a program means telling the Java Virtual Machine (JVM) to “Load the MyFirstApp class, then start executing its main() method. Keep running ’til all the code in main is finished.”

No matter how big or how many classes you have, there’s got to be a main() method to run the whole program.

1. Save name.java
2. Compile javac name.java
3. Run java name

## **Phrase-O-Matic How it works**

It takes the three sets of words, gets its length and use that length as a limiter for the random generator so it doesn't pick out of its length. Once random number is added, you can build a phrase using the 3 sets of words and print out its result.

- Create an array `String[] pets = {"Fido", "Zeus", "Bin"};`
- Get the length `int lengthPets = pets.length`
	- `.length` is a function to get the length of arrays
- Generate random numbers = `int randPets = randomGenerator.nextInt(lengthPets)`
	- `randomGenerator.nextInt` Gets a random number from the number we gave it which is the length of pets array.
- Build the phrase using string concatenation or separate variables
	```
	String s = pets[randPets]; // s is now the String "Fido" 
	s = s + " is a dog"; // s is now "Fido is a dog"
	```
