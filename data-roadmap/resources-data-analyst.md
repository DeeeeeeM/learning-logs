# 📚 Learning Resources Master List

> All resources used across the 6-month Data Analyst roadmap, organized by phase and topic.  
> Legend: 🆓 Free · 💰 Paid · 🎓 Free to audit · 📺 YouTube · 📰 Blog/Articles

---

## 🔵 Phase 1 — Foundations
*Python · SQL · Excel · Weeks 1–3*

### Python
| Resource | Type | Why It's Here |
|---|---|---|
| [Kaggle Python Course](https://www.kaggle.com/learn/python) | 🆓 | Best beginner Python for data — covers lists, dicts, loops, functions in a data context. Start here. |
| [freeCodeCamp Data Analysis with Python](https://www.freecodecamp.org/learn/data-analysis-with-python/) | 🆓 | Covers Pandas + NumPy with real projects. Good bridge from Python basics into data work. |
| [Real Python](https://realpython.com) | 🆓 | Deep, well-written tutorials on specific Python topics. Use when you need to understand something properly, not just make it work. |

### SQL
| Resource | Type | Why It's Here |
|---|---|---|
| [SQLBolt](https://sqlbolt.com) | 🆓 | The cleanest interactive SQL course online. Start here for SQL basics — no setup needed. |
| [SQLZoo](https://sqlzoo.net) | 🆓 | Practice SQL against real databases. Use after SQLBolt to build confidence on varied data. |
| [LeetCode SQL](https://leetcode.com/problemset/database/) | 🆓 | Interview-level SQL problems. Start with Easy, move to Medium by Phase 2. Use every Sunday. |
| [Mode SQL Tutorial](https://mode.com/sql-tutorial/) | 🆓 | Best resource for advanced SQL — window functions, CTEs, subqueries. Use in Phase 2. |

### Excel
| Resource | Type | Why It's Here |
|---|---|---|
| [Alex The Analyst — Excel Playlist (YouTube)](https://www.youtube.com/@AlexTheAnalyst) | 📺 🆓 | Most practical Excel-for-analysts content on YouTube. Covers Pivot Tables, XLOOKUP, dashboards. |
| [Chandoo](https://www.youtube.com/@chandoo_) | 📺 🆓 | Excel + Power BI tutorials. Very practical, beginner-friendly, covers PH-relevant business scenarios. |

## 🟢 Phase 2 — Analytics Core
*Pandas · NumPy · EDA · Statistics · Weeks 4–8*

### Pandas & NumPy
| Resource | Type | Why It's Here |
|---|---|---|
| [Kaggle Pandas Course](https://www.kaggle.com/learn/pandas) | 🆓 | The fastest way to get productive with Pandas. 6 lessons, all hands-on. Best quick Pandas course available. |
| [Real Python — Pandas EDA Guide](https://realpython.com/pandas-python-explore-dataset/) | 🆓 | Walks through a full EDA workflow step by step. Highly practical — read this before your first EDA project. |
| [Rob Mulla (YouTube)](https://www.youtube.com/@RobMulla) | 📺 🆓 | Live EDA walkthroughs on Kaggle datasets. Watch how a working data scientist actually explores data. |

### Statistics
| Resource | Type | Why It's Here |
|---|---|---|
| [Statistics with Python — Coursera](https://www.coursera.org/learn/statistics-with-python) | 🎓 | University of Michigan. Covers everything an analyst needs: distributions, hypothesis testing, correlations. Free to audit. |
| [StatQuest with Josh Starmer (YouTube)](https://www.youtube.com/@statquest) | 📺 🆓 | Best channel for understanding statistics intuitively. Watch when a concept isn't clicking. No heavy math required. |

### EDA & Datasets
| Resource | Type | Why It's Here |
|---|---|---|
| [Kaggle Datasets](https://www.kaggle.com/datasets) | 🆓 | Thousands of real datasets. Search "Philippines" for locally relevant data — e-commerce, COVID, demographics. |
| [Towards Data Science](https://towardsdatascience.com) | 📰 🆓 | Practitioner-written articles on EDA, analytics, and Python. Read 1 article per week minimum. |
| [DataTalks.Club](https://datatalks.club) | 🆓 | Free courses and community for data practitioners. Their free DE Zoomcamp is excellent for later. |

### Advanced SQL
| Resource | Type | Why It's Here |
|---|---|---|
| [Mode SQL — Window Functions](https://mode.com/sql-tutorial/sql-window-functions/) | 🆓 | The clearest explanation of window functions online. Return to this every time you get confused. |
| [LeetCode SQL — Medium](https://leetcode.com/problemset/database/) | 🆓 | Graduate to Medium difficulty by Week 5. These mirror real interview questions. |
| [StrataScratch](https://www.stratascratch.com) | 🆓 💰 | Real SQL interview problems from actual companies (Google, Airbnb, etc). Free tier is enough for Phase 2. |

## 🟡 Phase 3 — Dashboards & Visualization
*Power BI · Matplotlib · Seaborn · Storytelling · Weeks 9–14*

### Power BI
| Resource | Type | Why It's Here |
|---|---|---|
| [DataCamp Power BI Track](https://www.datacamp.com/tracks/data-analyst-in-power-bi) | 💰 | Co-created with Microsoft. The most structured Power BI curriculum available. Worth the subscription for this phase. Also prepares for the PL-300 cert. |
| [Guy in a Cube (YouTube)](https://www.youtube.com/@GuyInACube) | 📺 🆓 | Run by ex-Microsoft Power BI team. The most trusted Power BI channel. Watch for DAX, data modeling, and report design. |
| [Microsoft Learn — Power BI](https://learn.microsoft.com/en-us/training/powerplatform/power-bi) | 🆓 | Official Microsoft learning path. Free and surprisingly good. Use alongside DataCamp. |
| [Power BI Public Gallery](https://community.powerbi.com/t5/Data-Stories-Gallery/bd-p/DataStoriesGallery) | 🆓 | Browse real dashboards from the community. Study the good ones for layout and design ideas before building your own. |

### Python Visualization
| Resource | Type | Why It's Here |
|---|---|---|
| [Kaggle Data Visualization Course](https://www.kaggle.com/learn/data-visualization) | 🆓 | Seaborn-focused, fast, and practical. Covers the most useful chart types for an analyst. |
| [Matplotlib Documentation](https://matplotlib.org/stable/gallery/index.html) | 🆓 | The official gallery. When you need a specific chart type, find it here and adapt the example. |
| [Python Graph Gallery](https://python-graph-gallery.com) | 🆓 | Every chart type with ready-to-copy code. Bookmark this — you will use it constantly. |

### Data Storytelling
| Resource | Type | Why It's Here |
|---|---|---|
| [Storytelling with Data (Blog)](https://www.storytellingwithdata.com/blog) | 📰 🆓 | The definitive resource on communicating data. Read the blog before building any dashboard. The book is also worth buying. |
| [Storytelling with Data (YouTube)](https://www.youtube.com/@storytellingwithdata) | 📺 🆓 | Chart makeovers and before/after critiques. Watching these trains your eye for what good data viz looks like. |
| [Flowing Data](https://flowingdata.com) | 📰 🆓 | Weekly roundup of interesting data visualizations. Good for inspiration and staying curious. |

## 🟣 Phase 4 — Job-Ready
*Portfolio · Certifications · Interview Prep · Weeks 15–20*

### Certifications
| Resource | Type | Why It's Here |
|---|---|---|
| [Google Data Analytics Certificate — Coursera](https://www.coursera.org/professional-certificates/google-data-analytics) | 🎓 💰 | The most recognized entry-level data cert in PH job listings. Free to audit all 8 courses. Pay only if you want the certificate badge. |
| [Microsoft PL-300 — Power BI Data Analyst](https://learn.microsoft.com/en-us/credentials/certifications/power-bi-data-analyst-associate/) | 💰 | The official Microsoft Power BI cert. Strong signal for corporate and BPO analyst roles in PH. Pursue after Phase 3. |

### Interview Prep
| Resource | Type | Why It's Here |
|---|---|---|
| [StrataScratch](https://www.stratascratch.com) | 🆓 💰 | Real SQL + Python interview questions from Google, Meta, Airbnb, and others. The best interview prep resource for data roles. |
| [LeetCode SQL — Hard](https://leetcode.com/problemset/database/) | 🆓 | Graduate to Hard by Phase 4. If you can solve Hard SQL, you're ready for any PH interview. |
| [Interview Query](https://www.interviewquery.com) | 🆓 💰 | Data analyst interview questions + guides by company. Good for understanding what different companies actually ask. |

### Portfolio & Career
| Resource | Type | Why It's Here |
|---|---|---|
| [Codebasics DA Bootcamp](https://codebasics.io/courses/data-analyst-bootcamp) | 💰 | Affordable, project-driven bootcamp recommended by Filipino analysts. Good for capstone project structure. |
| [Jovian](https://jovian.com) | 🆓 | Host and share Jupyter notebooks publicly. Good alternative or addition to GitHub for showcasing EDA work. |
| [Data Portfolio Guide — dataquest.io](https://www.dataquest.io/blog/data-analyst-portfolio/) | 📰 🆓 | How to build a portfolio that gets you hired. Read this before starting Phase 4. |

### PH Job Boards
| Platform | Type | Notes |
|---|---|---|
| [Jobstreet Philippines](https://www.jobstreet.com.ph) | 🆓 | Largest local job board. Set alert: "data analyst" · Metro Manila or Remote |
| [LinkedIn Jobs](https://www.linkedin.com/jobs/) | 🆓 | Best for corporate and MNC roles. Set alert: "data analyst Philippines" |
| [Kalibrr](https://www.kalibrr.com) | 🆓 | PH-focused, strong tech and analytics listings. Often has startup roles not on Jobstreet. |
| [OnlineJobs.ph](https://www.onlinejobs.ph) | 🆓 | Remote-first. Foreign clients pay in USD — 2–3× local rates for the same role. |
